关于网测通

让常见网络检测任务更直观。

本站提供公网 IP 查询、IP 归属地查询、DNS 记录查询和 HTTP 请求延迟测量。所有检测在浏览器内发起，部分功能依赖公开第三方接口。

IP 位置是估计信息；DNS 查询展示的是指定公共解析器的结果；延迟测试不是 ICMP Ping，也不是上传下载测速。

网站不要求用户注册账户。若检测接口不可用，会显示错误，不生成模拟结果。

联系与反馈

反馈工具问题前，请尽量记录出错页面和显示的错误信息。

如果遇到查询失败，可以先重新加载网页，检查错误提示以及是否能够访问所用的第三方接口。

可以通过 GitHub Issues 问题反馈页面 提交错误描述（需要登录 GitHub，且仓库须启用 Issues 功能）。如果提示无法创建问题，说明该入口暂不可用；网站不会假装已经收到反馈。

请勿发送密码、身份证件或其他敏感信息。

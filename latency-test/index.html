Fetch 结束耗时（毫秒）

本工具仅测量指定服务的 no-cors Fetch 请求结束耗时，无法核对 HTTP 状态码。连接建立、浏览器缓存、CDN、目标服务策略及跨地区网络都可能影响结果。两个目标不是统一测量节点，结果不适合用于排名或判断整条宽带线路是否正常。

HTTP 延迟跟网速有什么区别？

这里测的是浏览器完成一次请求所花的时间，可能包括连接建立、TLS 握手及网络调度。它不同于 ICMP Ping，也不测量宽带最大下载或上传速度。

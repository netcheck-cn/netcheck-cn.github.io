网络延迟、抖动和网速有什么区别？

用常见的网页加载、视频会议与文件下载场景理解延迟、波动及带宽的区别。

下载很快，为什么开会还是卡？

大文件下载看重持续吞吐量，视频会议和远程操作却更怕请求响应慢、延迟忽高忽低以及丢包。宽带套餐标称速度很高，也不能保证所有网站和游戏都反应迅速。

三个指标各回答什么问题

  • 延迟：一次通信完成需要多久，常用毫秒描述。测试目标和测试方法改变，结果也会变。
  • 抖动：多次延迟测量间的变化。视频通话中偶尔停顿，可能比平均延迟本身更值得关注。
  • 吞吐量：单位时间传输多少数据。下载文件时更重要，受服务器速度、协议和连接状况等共同影响。

实际排查怎么选工具

网页点开很慢，先检查目标网站有没有加载大量资源；视频会议时声音断续，尽量在相同时间、同一网络环境下比较不同连接的波动；下载慢，则需要专门的下载测速或实际文件传输观察。

本站HTTP 延迟检测只对指定公开端点执行浏览器 Fetch 请求，测量请求结束耗时。它不是系统 ICMP Ping，无法验证目标 HTTP 状态，也不能代表游戏服务器延迟或完整上传下载速率。

别只盯着一个数字

做比较时更有用的是：相同目标、相近时间、相同设备条件下，多次测量是否持续差异明显。如果只有一次异常，先复测，避免根据单个样本判断整条网络有问题。

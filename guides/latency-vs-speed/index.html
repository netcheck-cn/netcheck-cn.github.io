网络延迟、抖动和网速有什么区别？

用常见的网页加载、视频会议与文件下载场景理解延迟、波动及带宽的区别。

下载很快，为什么视频会议仍然卡？

下载速度表示单位时间能传输多少数据；延迟表示一次通信需要多久。两者描述的是不同的网络体验。一条线路带宽很大，也可能因为路由绕行或拥塞出现较高延迟。

三个常见指标

延迟：网络请求从发出到收到响应所经历的时间，通常以毫秒表示。具体测量方法会影响结果。

波动：多次测量耗时的不稳定程度。视频会议、互动游戏通常比普通网页阅读更怕明显波动。

带宽和吞吐量：带宽可理解为连接容量，实际下载速度还受服务器、协议、设备和网络路径影响。

如何自己检查？

先用本站 HTTP 延迟检测观察固定端点多次请求耗时。如果结果波动很大，可以尝试切换 Wi-Fi 与移动网络重新测量。但请记住，这个结果不是 ICMP Ping，也不能直接代表其他网站或游戏服务器的连接体验。

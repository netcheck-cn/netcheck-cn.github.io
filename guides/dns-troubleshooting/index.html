DNS 解析失败怎么办？

网站打不开时如何依次检查域名拼写、DNS记录、NXDOMAIN与SERVFAIL等常见问题。

网站打不开，不一定就是断网

如果聊天软件能使用，只有一个网页提示找不到服务器，先不要急着更换所有网络设置。DNS 是把域名转换为相关记录的查询过程，出现问题可能发生在域名本身、解析服务或浏览器网络路径。

先检查域名有没有返回记录

  1. 复制浏览器地址栏中的域名，不要包含 https:// 或后面的网页路径。
  2. 打开本站 DNS 查询，先查 A，再查 AAAA。
  3. 如果返回 NXDOMAIN，检查输入错误、域名是否存在以及解析服务状态。
  4. 如果返回 NOERROR 但没有 A 记录，域名也可能只配置了其他类型记录，不能直接判定故障。

为什么 Google 与 Cloudflare 结果不同？

记录刚更新时，两家解析器可能持有不同的缓存；面向不同地区的 DNS 调度也可能给出不同地址。仅凭两组结果不同，不能断言 DNS 被污染。

什么时候再排查网络连接？

如果域名解析能稳定返回地址，但网页依然连接失败，问题可能发生在目标服务器、HTTPS 证书、网络路由或访问策略。此时继续反复修改 DNS 未必有效。

隐私说明

了解工具运行时会向哪些服务发送请求。

第三方网络请求

网站使用 Google Analytics 4 统计访问情况。查看当前公网 IP 时，浏览器可能连接 ipify（IPv4/IPv6）、icanhazip 等回显服务；查询 IP 归属地时会向 IPwho.is 发送 IP；批量 IP 查询会向 IPinfo Lite 发送所输入的 IP 地址及用于接口鉴权的访问令牌。DNS 查询会将域名发送给 Google Public DNS 或 Cloudflare DNS。HTTP 请求耗时检测根据选择访问 Google 或 Cloudflare 的公开端点。各服务可能收到连接 IP、请求时间及浏览器通常发送的请求信息；具体处理方式以相应服务隐私政策为准。

数据保留

本网站没有自建用户账户或后台数据库，也不会主动把输入内容保存到本站服务器。第三方服务及 GitHub Pages 托管方可能根据各自的隐私政策处理网络请求日志；本站无法控制其记录与保留。

浏览器权限

复制功能可能调用浏览器剪贴板权限。网站不会索取地理定位、摄像头或麦克风权限。

外部广告

广告横幅链接会跳转到第三方网站。只有你点击后才会打开广告主网站；对方的隐私规则独立适用。

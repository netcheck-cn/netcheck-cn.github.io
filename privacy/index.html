隐私说明

了解工具运行时会向哪些服务发送请求。

第三方网络请求

本机 IP 检测向 api64.ipify.org 发起请求，因此对方可能获取请求 IP 等常规连接信息。IP 归属地查询向 ipwho.is 发送待查询的 IP 地址。DNS 工具会把你输入的域名发送至 dns.google 和 cloudflare-dns.com。HTTP 延迟测试会向 www.google.com 发出若干请求。

数据保留

本网站没有自建用户账户或后台数据库，也不会主动把输入内容保存到本站服务器。第三方服务及 GitHub Pages 托管方可能根据各自的隐私政策处理网络请求日志；本站无法控制其记录与保留。

浏览器权限

复制功能可能调用浏览器剪贴板权限。网站不会索取地理定位、摄像头或麦克风权限。

外部广告

广告横幅链接会跳转到第三方网站。只有你点击后才会打开广告主网站；对方的隐私规则独立适用。

访问统计与第三方服务

本站使用 Google Analytics 4 统计页面访问情况。Google 可能通过浏览器请求接收设备、访问行为与网络信息；具体处理方式请参考 Google 隐私政策。IP 查询、DNS 查询和延迟检测会向页面说明的第三方接口发送必要请求。本站不要求注册账户。
